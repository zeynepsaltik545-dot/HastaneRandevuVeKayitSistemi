# 🏥 Hastane Randevu ve Kayıt Sistemi

Bu proje, hastaların kolay bir şekilde kayıt olabildiği, randevu oluşturabildiği ve hastane yönetim işlemlerinin dijital ortamda gerçekleştirilebildiği bir hastane otomasyon sistemi olarak geliştirilmiştir. Projede hasta ve admin (sistem yöneticisi)   panelleri bulunmaktadır. Kullanıcılar sisteme giriş yaparak kendilerine ait işlemleri gerçekleştirebilmekte, doktorlar randevularını görüntüleyebilmekte ve admin (sistem yöneticisi) paneli üzerinden branş, doktor ve duyuru yönetimi yapılabilmektedir. Proje geliştirilirken C# programlama dili, Windows Forms yapısı, SQL Server veri tabanı ve ADO.NET teknolojileri kullanılmıştır. Amaç, hastane içerisindeki randevu ve kayıt süreçlerini daha düzenli, hızlı ve kullanıcı dostu bir hale getirmektir.
